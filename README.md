# FuntoChat

A basic chatbox platform website built with Vite + React and connected to Supabase (realtime messages).

- Live site: https://funtochat.vercel.app
- GitHub: https://github.com/tarunkonga89-blip/funtochat

## Local development

```bash
npm install
npm run dev
```

Without Supabase environment variables the app runs in **demo mode** (messages stay in the browser only).

## Supabase setup

1. Create a Supabase project.
2. In the SQL editor, create a `messages` table and enable realtime:

```sql
create table if not exists public.messages (
  id bigint generated by default as identity primary key,
  content text not null,
  username text not null default 'Guest',
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

alter publication supabase_realtime add table public.messages;

-- Basic RLS for a public demo chat (adjust for production)
alter table public.messages enable row level security;

create policy "Allow read access" on public.messages
  for select using (true);

create policy "Allow insert access" on public.messages
  for insert with check (true);
```

3. Copy `.env.example` to `.env` (or set env vars in Vercel) and fill in:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

Find these in Supabase: **Project Settings → API**.

## Deploy (Vercel)

- Import the GitHub repository in Vercel.
- Framework preset: **Vite** (build `npm run build`, output `dist`).
- Add the `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` environment variables.
- Deploy.
